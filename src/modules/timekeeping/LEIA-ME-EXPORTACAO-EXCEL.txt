EXPORTAÇÃO EXCEL - PONTO DIÁRIO

Esta versão usa xlsx-js-style para manter cores, bordas, fontes e preenchimentos no arquivo Excel.

Antes de rodar o frontend, instale no projeto:

npm install xlsx-js-style

Depois substitua a pasta:
frontend/src/modules/timekeeping

pela pasta timekeeping deste ZIP.

A exportação foi ajustada para:
- visual no padrão PONTO DIÁRIO;
- cabeçalho azul e tabela zebrada;
- campo Dia de referência ao lado do Período;
- status com cores configuradas no próprio sistema.
